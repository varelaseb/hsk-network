HSK bubbles

docs / specs / hsk-bubbles.spec.html

A bubble shooter game on the HSK network site, built for a phone held in one hand.

The learner aims and shoots character bubbles; connected bubbles that spell an HSK word pop and show the word with its Zhuyin and English, and bubbles left hanging fall.

It reuses the network's word data file unchanged; script, reading aid, levels, and sources follow the network defaults.

User stories

As a learner on a phone, I aim with one thumb and shoot character bubbles into a board, and it feels smooth, quick, and polished.

As a learner, when my shot spells an HSK word with connected bubbles, the word pops and I see it with its Zhuyin and English, so I learn words while playing.

As a learner, I can look up any character on the board or in the launcher to see its Zhuyin and English without shooting, so I learn characters I do not know yet.

As a learner, bubbles left hanging after a pop fall away and score a bonus, so I plan shots that clear more.

As a learner, I see my score, round, words left, and best score, the game gets harder each round, and it ends when the bubbles reach the bottom line.

As a learner, each round is a small deck of words to make: every bubble on the board belongs to a word I still have to make, and the launcher only hands me characters I still need, so the board never turns into a wall I cannot clear.

As a learner, I choose which HSK levels the game uses, so I practice one level at a time.

As a learner, after a game I review the words I popped and can open each in the network.

As a learner, I hear each word said aloud as it pops, and I can turn that off.

As a learner, the game plays no effect sounds or vibration until I turn them on, and it respects my reduced-motion setting.

As a learner on an iPhone in pinyin mode, the bubbles show characters in their mainland shapes, the same as the network, so I learn the shapes I will read.

As a learner whose device uses the dark appearance, the game's cards and screens are dark too, so nothing glares white over the night board.

As a maintainer, the game rules are a separate module with unit tests that run on every pull request, and the game ships with the site on every merge to main.

Modular boundaries

Game rules own the board grid, shot paths and wall bounces, where a shot settles, round decks, word detection, falling, launcher bubble choice, scoring, rounds, ceiling, and game over. Caller-facing seam: a pure module that takes a word list, levels, and a seed, and answers each shot angle with the resulting board and events (settled, popped words, fallen bubbles, words left, score, round clear, game over). Dependency direction: self-contained; no page, timer, randomness source, or storage, so the same seed and shots always give the same game. Observable scope: rule unit tests.

The game page owns screens, touch and pointer aiming, drawing and animation, word cards, when to say a popped word, effect sounds and vibration, settings, and best score. Caller-facing seam: the public game page. Dependency direction: self-contained; it consumes the game rules, the shared voice module, and the network's word data file read-only; it holds no dictionary logic and changes nothing in the network page or pipeline. Observable scope: what a learner sees, hears, and touches.

The network's data pipeline stays the single source of words, Traditional forms, Zhuyin, definitions, levels, character readings, and pronunciation recordings. Caller-facing seam: the existing graph data file and its schema in the network spec. Dependency direction: self-contained; the game depends on the file; the pipeline knows nothing of the game, and the game adds no data file. Observable scope: the committed graph data file.

Delivery runs the rule tests beside the existing suite on every pull request and publishes the game with the site directory on every merge to main. Caller-facing seam: the pull request test check and the public address. Dependency direction: external provider GitHub Actions and GitHub Pages, through the existing workflows. Observable scope: check status and the live game page.

01

Game design

The rules that make it a word game rather than a color game.

QuestionRule
What forms a wordA chain of bubbles, each touching the one before, whose characters read an unfinished word of the round's deck in order, and that includes the bubble just shot at any position; it may run in any direction and bend, and uses no bubble twice. Building a word from either end, or dropping its middle character into a gap, both count.
Which words countDeck words come from every HSK word of 2 to 4 characters in the levels switched on (133 two-character, 10 three-character, and 1 four-character word across HSK 1 and 2); single-character words are never dealt. Only words of the current deck pop.
Round deckEach round deals a deck of distinct words, drawn by the seed: 8 in round 1, one more each round, up to 12. A deck word is finished when it pops, or when none of its characters is left on the board. When a word finishes, every bubble whose character belongs to no unfinished deck word drops with that shot, repeating until none is left over, so no bubble is ever an orphan. The round is cleared when every deck word is finished, which leaves the board empty.
Which characters appearBoards are built by laying whole deck words along chains, cycling through the deck so each deck word is laid at least once, and a ceiling drop's new row is laid the same way from unfinished deck words only. Each launcher bubble is a character of an unfinished deck word, drawn three times in four from characters that complete an unfinished deck word with a bubble a shot can reach, and otherwise from any character of an unfinished deck word; when neither the current nor the next bubble completes one, the next one is always a completing character. When no unfinished deck word can be completed by one shot, as when falls leave a longer word with too few characters on the board, each launcher bubble is instead a character of such a word that, placed touching one of its bubbles a shot can reach, reads with it two neighboring characters of that word in order, so the learner rebuilds the word over several shots; only the full word pops.
ScoringEach popped character scores 100 times the word's length, so longer words pay more per character; each fallen bubble, including a left-over bubble of a finished word, scores 50, doubling for every 5 in one drop. Consecutive shots that pop multiply that shot's points by 2, 3, 4, then 5 at most; a shot that pops nothing resets the combo to 1. Clearing a round scores 1000 times the round number.
RoundsRound 1 starts with 5 rows and the ceiling drops one row after 8 shots in a row without a pop. Each next round starts with one more row, up to 9, and allows one shot fewer, down to 4, with its larger deck by the rule in Round deck.
Game overThe game ends when a bubble settles below the bottom line, which sits two bubble rows above the launcher. The line is dashed and glows when the lowest bubble is one row above it. A ceiling drop that pushes a bubble below the line also ends the game.
Popped word reviewThe game-over screen lists the words popped this game, newest first, each once. Tapping one opens the network page focused on that word with its card open.
Getting to the gameThe network page's "Play" link opens the game; the game's start and game-over screens link back to the network.

Word links use the network's word link address, defined by the network page, which also owns its "Play" link.

02

Board and rules

A hex grid of character bubbles hanging from the ceiling.

  • The board is 8 bubbles wide with every other row offset by half a bubble; bubble size is the play width divided by 8.
  • A shot flies straight at a fixed speed, reflects off the side walls any number of times, and stops when it touches a bubble or the ceiling; it settles into the nearest free grid cell.
  • Aim is limited to between 10 and 170 degrees from the horizontal, so no shot runs flat along the launcher line.
  • After a shot settles: find words through it by the word rule in Game design, pop the bubbles of every word found, then drop every bubble no longer connected to the ceiling, then finish deck words and drop left-over bubbles by Round deck, then score, then check round clear, ceiling, and game over, in that order.
  • When one shot forms several words, all pop and their cards show one after another, longest word first.
  • A word card shows the word's data entry; when two entries share the Traditional form, it shows each reading's Zhuyin with that entry's first definition.
  • A character card shows the character's own readings from the character table in the word data, each as its reading in the current script mode, Zhuyin by default, with its first English definition, per the network's script setting. Inspecting never shoots, swaps, or changes the board. A character card closes on the next tap, click, or key press.
  • Launcher bubbles are chosen by the rule in Game design from characters of unfinished deck words only, so the launcher never hands a character no word still needs.
  • Each game takes a seed; the same seed, levels, and shots replay the same game.

Feel

  • Drawing runs once per display frame and holds 60 frames a second on a mid-range phone; character bubbles are drawn once at device resolution and reused, so text stays sharp.
  • Shots ease into place with a small settle bounce; pops burst into a few particles with a light screen shake; falling bubbles drop with gravity and slight spin; scores count up.
  • With reduced motion requested, pops and falls fade, with no particles, shake, or spin.
  • Pronunciation is on at first: each popped word is said once as its card shows. It plays the word's recording from the site; a word without one is spoken by a Taiwan Mandarin voice on the device; with no such voice it stays silent. Voices that send text off the device are never used. When one shot pops several words, each is said in card order. The pronunciation control is the site-wide Voice setting: it turns pronunciation on or off here and on the network, and the choice is remembered on the device. The choice of source is made by the shared voice module.
  • Effect sounds and vibration are off at first; one effects control turns both on, and the choice is remembered on the device. Effect sounds are generated in the page, so no effect audio file is loaded. Vibration fires only where the device supports it.
  • The game area fills the visual viewport within the safe areas, blocks page scroll, pull-to-refresh, double-tap zoom, and text selection while playing, and every button is at least 44px.
  • Type follows the network's look: characters and Zhuyin in the vendored Chinese face (Noto Sans CJK TC), drawn into bubbles only once it has loaded, English and scores in the vendored sans; word cards use the network's headword Zhuyin layout and cleaned senses, and the review list shows Zhuyin on one line.
  • Best score, level switches, and the pronunciation and effects choices are remembered on the device only; the pronunciation choice is shared with the network.
  • Bubbles, word cards, and the review list follow the network's script setting, shown on the start screen; switching it relabels the bubbles only, as word detection stays keyed by Traditional characters. Bubbles take their glyph shapes from the faces the script setting names, never from a language tag on the canvas, so pinyin mode shows mainland shapes on every browser.
  • The game uses the network's color, surface, and motion tokens in their game column, and in the dark appearance its column, so cards and screens turn dark over the same night board, with the HSK 1 and HSK 2 colors on word cards and in the switches and level always named in text; the start screen is the title, the level chips, the best score, one ink Play pill, and the pronunciation and effects controls as a quiet row, with nothing else above the fold.
