HSK bubbles

docs / specs / hsk-bubbles.spec.html

A bubble shooter game on the HSK network site, built for a phone held in one hand.

The learner aims and shoots Traditional character bubbles; connected bubbles that spell an HSK word pop and show the word with its Zhuyin and English, and bubbles left hanging fall.

It reuses the network's word data file unchanged; script, reading aid, levels, and sources follow the network defaults.

User stories

As a learner on a phone, I aim with one thumb and shoot character bubbles into a board, and it feels smooth, quick, and polished.

As a learner, when my shot spells an HSK word with connected bubbles, the word pops and I see it with its Zhuyin and English, so I learn words while playing.

As a learner, bubbles left hanging after a pop fall away and score a bonus, so I plan shots that clear more.

As a learner, I see my score, round, and best score, the game gets harder each round, and it ends when the bubbles reach the bottom line.

As a learner, I choose which HSK levels the game uses, so I practice one level at a time.

As a learner, after a game I review the words I popped and can open each in the network.

As a learner, the game is silent until I turn sound or vibration on, and it respects my reduced-motion setting.

As a maintainer, the game rules are a separate module with unit tests that run on every pull request, and the game ships with the site on every merge to main.

Modular boundaries

Game rules own the board grid, shot paths and wall bounces, where a shot settles, word detection, falling, launcher bubble choice, scoring, rounds, ceiling, and game over. Caller-facing seam: a pure module that takes a word list, levels, and a seed, and answers each shot angle with the resulting board and events (settled, popped words, fallen bubbles, score, round clear, game over). Dependency direction: self-contained; no page, timer, randomness source, or storage, so the same seed and shots always give the same game. Observable scope: rule unit tests.

The game page owns screens, touch and pointer aiming, drawing and animation, word cards, sound and vibration, settings, and best score. Caller-facing seam: the public game page. Dependency direction: self-contained; it consumes the game rules and the network's word data file read-only; it holds no dictionary logic and changes nothing in the network page or pipeline. Observable scope: what a learner sees, hears, and touches.

The network's data pipeline stays the single source of words, Traditional forms, Zhuyin, definitions, and levels. Caller-facing seam: the existing graph data file and its schema in the network spec. Dependency direction: self-contained; the game depends on the file; the pipeline knows nothing of the game, and the game adds no data file. Observable scope: the committed graph data file.

Delivery runs the rule tests beside the existing suite on every pull request and publishes the game with the site directory on every merge to main. Caller-facing seam: the pull request test check and the public address. Dependency direction: external provider GitHub Actions and GitHub Pages, through the existing workflows. Observable scope: check status and the live game page.

01

Game design

The rules that make it a word game rather than a color game.

QuestionRule
What forms a wordA chain of bubbles, each touching the one before, whose characters read an HSK word in order, and that includes the bubble just shot at any position; it may run in any direction and bend, and uses no bubble twice. Building a word from either end, or dropping its middle character into a gap, both count.
Which words countEvery HSK word of 2 to 4 characters in the levels switched on (133 two-character, 10 three-character, and 1 four-character word across HSK 1 and 2); single-character words never pop on their own.
Which characters appearBoards are built by laying whole words of the levels on along chains, so every bubble starts with a word partner. Each launcher bubble is drawn three times in four from characters that complete a word with a bubble a shot can reach, and otherwise from any character still on the board; when neither the current nor the next bubble completes a word, the next one is always a completing character.
ScoringEach popped character scores 100 times the word's length, so longer words pay more per character; each fallen bubble scores 50, doubling for every 5 in one drop. Consecutive shots that pop multiply that shot's points by 2, 3, 4, then 5 at most; a shot that pops nothing resets the combo to 1. Clearing a round scores 1000 times the round number.
RoundsRound 1 starts with 5 rows and the ceiling drops one row after 8 shots in a row without a pop. Each next round starts with one more row, up to 9, and allows one shot fewer, down to 4. A round is cleared when the board is empty.
Game overThe game ends when a bubble settles below the bottom line, which sits two bubble rows above the launcher. The line is dashed and glows when the lowest bubble is one row above it. A ceiling drop that pushes a bubble below the line also ends the game.
Popped word reviewThe game-over screen lists the words popped this game, newest first, each once. Tapping one opens the network page focused on that word with its card open.
Getting to the gameThe network page has a "Play" link beside its level panel; the game's start and game-over screens link back to the network.

Word links use the network's word link address, defined by the network page, which also owns its "Play" link.

02

Board and rules

A hex grid of character bubbles hanging from the ceiling.

  • The board is 8 bubbles wide with every other row offset by half a bubble; bubble size is the play width divided by 8.
  • A shot flies straight at a fixed speed, reflects off the side walls any number of times, and stops when it touches a bubble or the ceiling; it settles into the nearest free grid cell.
  • Aim is limited to between 10 and 170 degrees from the horizontal, so no shot runs flat along the launcher line.
  • After a shot settles: find words through it by the word rule in Game design, pop the bubbles of every word found, then drop every bubble no longer connected to the ceiling, then score, then check round clear, ceiling, and game over, in that order.
  • When one shot forms several words, all pop and their cards show one after another, longest word first.
  • A word card shows the word's data entry; when two entries share the Traditional form, it shows each reading's Zhuyin with that entry's first definition.
  • Launcher bubbles are chosen by the rule in Game design from characters still on the board, so a board never strands the learner with a character that has no partner left.
  • Each game takes a seed; the same seed, levels, and shots replay the same game.

Feel

  • Drawing runs once per display frame and holds 60 frames a second on a mid-range phone; character bubbles are drawn once at device resolution and reused, so text stays sharp.
  • Shots ease into place with a small settle bounce; pops burst into a few particles with a light screen shake; falling bubbles drop with gravity and slight spin; scores count up.
  • With reduced motion requested, pops and falls fade, with no particles, shake, or spin.
  • Sound and vibration are off at first; one sound control turns both on, and the choice is remembered on the device. Sounds are generated in the page, so no audio file is loaded. Vibration fires only where the device supports it.
  • The game area fills the visual viewport within the safe areas, blocks page scroll, pull-to-refresh, double-tap zoom, and text selection while playing, and every button is at least 44px.
  • Characters use the device's Traditional Chinese system font; no web font is downloaded.
  • Best score, level switches, and the sound choice are remembered on the device only.
  • The game shares the network page's colors for HSK 1 and HSK 2 on word cards and in the switches, with level always named in text.

  • Word detection: straight, bent, and reversed chains; three- and four-character words; a shot completing two words; a single-character word that does not pop; a chain not through the shot bubble that does not pop; levels switched off.
