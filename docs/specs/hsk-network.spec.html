HSK network

docs / specs / hsk-network.spec.html

A public static website: a force-directed graph of the HSK 1 and HSK 2 vocabulary in Traditional characters.

Words that share a character cluster around that character; each word shows its Zhuyin and English definitions on hover or tap.

User stories

As a learner, I see every HSK 1 and HSK 2 word as a network in which words sharing a character gather around that character, so I learn characters through related words.

As a learner, I hover or tap a word to see its Traditional form, Zhuyin, English definitions, and HSK level.

As a learner, I type into a search box to find a word and the graph brings it into view.

As a learner, I switch each HSK level on or off so I can study one level's words at a time.

As a learner on a phone, I can read, pan, zoom, and tap the graph as comfortably as on a desktop.

As a learner, I can see where the vocabulary and definitions come from and under which licenses.

As a maintainer, I rebuild the word data with one command, and an automated test suite proves the data correct on every pull request.

Modular boundaries

The data pipeline owns turning the HSK lists and CC-CEDICT into the graph data: matching, Traditional forms, Zhuyin, definitions, hubs, and links. Caller-facing seam: one build command that writes the graph data file, plus that file's schema below. Dependency direction: external provider; it downloads CC-CEDICT at build time only, and nothing calls back into it. Observable scope: the committed graph data file and the build's error list.

The site owns layout, rendering, hover and tap cards, search, legend, and the Sources footer. Caller-facing seam: the public page. Dependency direction: self-contained; it consumes the graph data file and the vendored graph library only and holds no dictionary logic. Observable scope: what a learner sees and touches.

Delivery owns tests on every pull request and publishing the site on every merge to main. Caller-facing seam: the pull request test check and the public address. Dependency direction: external provider GitHub Actions and GitHub Pages; it runs the repository's own test command and publishes the site directory unchanged. Observable scope: check status and the live site.

02

Graph model

Word nodes link only to character hubs.

Each HSK list entry is one word node, so a character with two listed readings, such as 長 cháng and 長 zhǎng, is two word nodes told apart by their Zhuyin.

A character hub exists for every Traditional character that appears in two or more word nodes, counting a single-character word as containing its character.

Each word links once to the hub of each distinct character it contains; a word whose characters are all unshared stays unlinked and floats near the center.

Word nodes are larger than hubs; hubs are gray and labeled with their character in a smaller size.

Matching an entry to CC-CEDICT

  1. Candidates are CC-CEDICT entries whose Simplified form equals the list entry's and whose pinyin equals it after both are reduced to lowercase syllables with tone numbers, treating a missing tone as neutral (5) and ü as u:.
  2. When both a capitalized (proper noun) and a lowercase candidate match, keep those whose capitalization matches the list entry.
  3. Remaining candidates sharing one Traditional form merge their definitions in dictionary order, de-duplicated.
  4. Definitions that only point elsewhere, those starting "variant of", "old variant of", "see ", or "surname ", are dropped unless nothing else remains.
  5. No candidate, or candidates with differing Traditional forms, fails the build and names each such entry.
  6. A small committed override file resolves each failing entry by naming the CC-CEDICT Traditional form and pinyin to use, with a one-line reason per override.
  7. A list word absent from CC-CEDICT is overridden with its Traditional form, pinyin, and hand-written English definitions, and its reason says the definitions are not from CC-CEDICT.

Zhuyin

Each numbered pinyin syllable converts to Zhuyin by a complete syllable table, keeping dictionary tones with no tone sandhi.

Syllables are separated by one space.

Graph data file

One JSON file in the site directory; the pipeline writes it and the site reads it.

{
  "meta": {
    "cedictRelease": "2026-10-01",
    "hskSource": "https://github.com/clem109/hsk-vocabulary@<commit>"
  },
  "words": [
    {
      "id": "1-128",
      "level": 1,
      "trad": "學生",
      "simp": "学生",
      "pinyin": "xue2 sheng5",
      "zhuyin": "ㄒㄩㄝˊ ˙ㄕㄥ",
      "defs": ["student", "schoolchild"]
    }
  ],
  "hubs": [
    { "id": "c-學", "char": "學" }
  ],
  "links": [
    { "word": "1-128", "hub": "c-學" }
  ]
}

A word id is its level and its position in that list, so both readings of one character stay distinct.

Page

One screen: search on top, graph filling the rest, card on demand.

On load, and on window resize, the view fits the whole settled graph.

Focusing a word pans and zooms so it is centered at a readable size, highlights it with its hubs and the words sharing those hubs, and dims the rest.

The legend is the level panel: each level's row shows its color, its name, and an on/off switch, both on at load.

Switching a level off hides its words and their links, hides any hub left with fewer than two visible words, closes a card for a hidden node, and removes that level's words from search results; the layout of visible nodes does not jump.

The last level that is on cannot be switched off.

HSK 1 and HSK 2 use a color pair distinguishable with common color blindness; the legend and the card both name the level in text.

Every tappable control and the search box are at least 44px tall, and the search box text is at least 16px so phones do not zoom on focus.

A "Sources" footer link opens the credits named in the Sources acceptance criterion.

Test suite

  • Known words: at least ten reference words, including 學生, 喜歡, 長 in both readings, 得 in both readings, 中國, and 女兒, each checked for Traditional form, exact Zhuyin, and an expected English gloss.
  • Zhuyin conversion: every tone, neutral tone, erhua, ü syllables, and zero-initial syllables such as yi, wu, and yu.
  • Completeness: every entry of both committed HSK lists appears once, with its level, and nothing else.
  • Links: hubs and links recomputed from the words' Traditional forms equal the committed ones.
  • Matching: the match rules above, against a few fixture dictionary lines, including a failing entry and an override.
  • Static: no site file references an address outside the site.
